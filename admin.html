O que esta tela não resolve sozinha

Hoje o catálogo de exercícios é código compilado dentro do app (src/data/exercises.js), e as imagens entram como require() estático. Enquanto isso não mudar, "publicar" um exercício novo por este painel significa, na prática, mandar uma nova versão do app para a loja — não uma publicação instantânea. Três peças precisam sair de dentro do app antes deste painel funcionar de verdade:

  • Catálogo fora do app (banco de dados em vez de arquivo compilado) — Backend Infrastructure.
  • Imagens fora do app (servidas por URL em vez de require()) — Backend Infrastructure.
  • Validação do motor acessível por API, para o painel chamar sem depender de build do app — Dev Mobile + Backend Infrastructure.
  • Confirmação de GPS das academias de atuação do personal (Área do Parceiro) precisa de uma chave de API do Google Maps — dono ainda não definido, ver P8 no STATUS.md.

A tela acima já está desenhada para o dia em que essas peças existirem. Não prometo que ela funciona hoje.
